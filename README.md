# تحدي الـ 90 يوم — إنجليزي
 
صفحة ويب واحدة (بدون سيرفر أو بيلد) لتتبّع تحدّي تعلّم الإنجليزي على مدار 90 يوم.
كل يوم بموضوعه، كلماته، بلوكاته (Chunks)، وأسئلة تحقق — والتقدّم بيتحفظ محلياً
على متصفحك (`localStorage`) من غير أي حساب أو تسجيل.
 
🔗 **جرّبها هنا:** https://oniseg.github.io/language/
 
## المميزات
 
- 90 يوم مقسّمين على 5 مراحل، كل يوم فيه: مصدر مذاكرة، شروط عبور، جدول كلمات،
  بلوكات، أسئلة تحقق مع إجابات.
- تتبّع تقدّم (نسبة مئوية + عداد أيام) محفوظ في المتصفح.
- وضع فاتح/غامق (يتبع إعداد الجهاز تلقائياً، وقابل للتبديل يدوياً).
- تصميم متجاوب لكل أحجام الشاشات، ودعم كامل للتنقّل بالكيبورد.
## طريقة الاستخدام
 
افتح `index.html` في أي متصفح — مفيش تثبيت ولا اعتماديات مطلوبة.
 
## البنية
 
الملف كله (HTML + CSS + JS + بيانات الأيام التسعين) في `index.html` واحد
عمداً، عشان يفضل سهل النشر والفتح المباشر من غير أدوات بناء.
