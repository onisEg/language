# تحدي الـ 90 يوم — إنجليزي

تطبيق ويب (بدون سيرفر أو بيلد) لتتبّع تحدّي تعلّم الإنجليزي على مدار 90 يوم.
كل يوم بموضوعه، كلماته، بلوكاته (Chunks)، وأسئلة تحقق — والتقدّم بيتحفظ محلياً
على متصفحك (`localStorage`) من غير أي حساب أو تسجيل.

🔗 **جرّبها هنا:** https://oniseg.github.io/language/

## المميزات

- 90 يوم مقسّمين على 5 مراحل، كل يوم فيه: مصدر مذاكرة، شروط عبور، جدول كلمات،
  بلوكات، أسئلة تحقق مع إجابات.
- **نطق صوتي** لكل كلمة إنجليزية وكل بلوك — بيشتغل بـ `speechSynthesis` بتاع
  المتصفح نفسه، من غير أي مكتبة أو مفتاح API. لو المتصفح مش مدعّم، الأزرار
  بتختفي لوحدها.
- **بحث فوري** في أرقام الأيام، عناوين المواضيع (عربي/إنجليزي)، وكل الكلمات
  والبلوكات جوّه المواضيع.
- **زرار «كمّل من هنا»** بيوَدّيك على أول يوم لسه مخلّصتوش ويفتحه.
- **سلسلة حقيقية (streak)** محسوبة من تواريخ فعلية، مع أطول سلسلة وصلتها.
- **يتثبّت كتطبيق (PWA)** ويشتغل أوفلاين بعد أول فتح.
- تتبّع تقدّم (نسبة مئوية + عداد أيام).
- وضع فاتح/غامق (يتبع إعداد الجهاز تلقائياً، وقابل للتبديل يدوياً).
- تصميم متجاوب لكل أحجام الشاشات، ودعم كامل للتنقّل بالكيبورد.

## طريقة الاستخدام

افتح `index.html` في أي متصفح — مفيش تثبيت ولا اعتماديات مطلوبة.

للتثبيت على الموبايل: افتح اللينك في المتصفح واختار «إضافة إلى الشاشة الرئيسية».

> ملاحظة: خاصية الأوفلاين (Service Worker) محتاجة `http://` أو `https://`،
> يعني مش هتشتغل لو فتحت الملف بـ `file://` مباشرة — باقي المميزات هتشتغل عادي.

## البنية

```
index.html            التطبيق كله: HTML + CSS + JS + بيانات الأيام التسعين
sw.js                 Service Worker للأوفلاين والكاش
manifest.webmanifest  إعدادات التثبيت كتطبيق
icon.svg              أيقونة التطبيق (SVG)
icon-192.png          أيقونة إضافية لأجهزة iOS
icon-512.png          أيقونة إضافية
```

`index.html` لسه ملف واحد عمداً، عشان يفضل سهل النشر والفتح المباشر من غير أدوات
بناء. الملفات التانية صغيرة وموجودة بس عشان الـ PWA — المتصفح بيطلبها لوحده
ومحتاجة تكون ملفات منفصلة (الـ Service Worker مينفعش يتحطّ inline).

## تخزين التقدّم

المفتاح: `eng90_progress_v2` — بيخزّن تاريخ إنهاء كل يوم:

```json
{ "1": "2026-03-14", "2": "2026-03-15" }
```

النسخة القديمة (`eng90_progress_v1`) كانت بتخزّن `true` بس من غير تاريخ.
التطبيق بيهاجرها تلقائياً أول ما يفتح، وبيحطّ `"?"` مكان التاريخ المجهول —
اليوم بيفضل مشطوب عادي، بس مش بيدخل في حساب السلسلة.

## تحديث النسخة

لو عدّلت `index.html`، غيّر رقم `CACHE_VERSION` في `sw.js` عشان المستخدمين
اللي مثبّتين التطبيق يوصلهم التحديث.
